LOKI + GRAFANA MONITORING SETUP NOTES
======================================

1. HOW LOKI WAS STARTED (local Docker)
---------------------------------------
Loki was run locally using the official Grafana Docker image:

    docker run -d --name=loki -p 3100:3100 grafana/loki:2.9.0 -config.file=/etc/loki/local-config.yaml

Grafana (to visualize the logs) was run alongside it:

    docker run -d --name=grafana -p 3000:3000 grafana/grafana:latest

Grafana was then opened at http://localhost:3000 (default login admin/admin),
and Loki was added as a data source using URL: http://localhost:3100


2. LOG FORWARDING (container/Nomad logs -> Loki)
--------------------------------------------------
Promtail was used to forward Docker container logs into Loki:

    docker run -d --name=promtail \
      -v /var/lib/docker/containers:/var/lib/docker/containers:ro \
      -v $(pwd)/promtail-config.yaml:/etc/promtail/config.yml \
      grafana/promtail:2.9.0 -config.file=/etc/promtail/config.yml

promtail-config.yaml scrapes the standard Docker container log path
(/var/lib/docker/containers/*/*.log) and pushes entries to the Loki
push API at http://loki:3100/loki/api/v1/push.

For the Nomad job (hello.nomad), the docker driver's default logging
(stdout/stderr) is collected by Docker itself, which Promtail then
picks up from the container log path above — no extra config needed
inside the Nomad job file.


3. COMMAND USED TO VIEW LOGS
-------------------------------
Logs can be queried directly from Loki using logcli:

    logcli query '{job="containerlogs"}' --addr=http://localhost:3100

Or viewed visually in Grafana:
  - Go to http://localhost:3000
  - Open "Explore"
  - Select the "Loki" data source
  - Run the query: {job="containerlogs"}

This shows the "Hello, DevOps!" output from the hello-devops container
in near real-time.
